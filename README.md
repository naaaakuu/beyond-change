# Beyond Change

A clean, modern, and responsive website exploring the concept of **"Beyond Change"** explained in simple English.

## About

Change is inevitable, but going *beyond change* means purposeful progress—moving beyond passive reaction to intentional transformation and long-term positive impact.

## Features

- Clean, modern responsive design
- Elegant typography and dark mode aesthetic
- Written in simple, accessible English
- Pure HTML & CSS with zero external script dependencies
